Готов к игре?

  1. Установи Novetus для Windows и нужный клиент.
  2. В Novetus установи обработчик ссылок: Install URI / Novetus URI (название зависит от сборки).
  3. Нажми зелёную кнопку Play и разреши браузеру открыть Novetus.

Сервер должен быть запущен и доступен по указанным IP и порту. Сайт не проверяет его доступность и не запускает сервер. Для игры с телефона нужен совместимый клиент — сам сайт его не заменяет.

Публикация: заполни форму → отправь Issue на GitHub → нажми «Обновить». Чтобы убрать плейс, закрой его Issue. Чтобы изменить — отредактируй JSON в Issue.

Запускаем Novetus

Разреши браузеру открыть приложение. Если окно не появилось, установи обработчик Novetus URI.
